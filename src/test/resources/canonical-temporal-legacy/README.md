# Frozen native temporal snapshots

These fixtures were generated by the pre-metadata implementation at `d1f76c64`
(the independently qualified `081e3c18` native implementation plus its unwired metadata helper).
They are native recovery fixtures, not stock Flink canonical savepoints.

Both input schemas are `[k BIGINT, v BIGINT, rt BIGINT]`. Each writer receives one build row
`[1, 10, 100]` and two identical probe rows `[1, 10, 100]`, all at processing time 1000.
The suffix selects retention 0 or 100 ms (absolute cleanup deadline 1150).
The raw fixtures have two or three framed sections. The RocksDB checkpoints use the original
global unsigned probe sequence, with no stock-index flags or metadata table/version marker.
Only the SST and required manifest files are retained; RocksDB recreates options and logs on open.
Tests read these bytes directly without using the current writer to fabricate a legacy format.
